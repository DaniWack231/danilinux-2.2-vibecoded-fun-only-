## SpaceCadetPinball engine (3D Pinball: Space Cadet)
* Source: https://github.com/k4zmu2a/SpaceCadetPinball (GPL-2.0-or-later)
* The full engine source ships on this image in:
  /usr/local/src/SpaceCadetPinball-src.tar.gz
* The original game data files (PINBALL.DAT, sounds, etc.) come from a
  personal Windows XP installation. They are the property of
  Cinematronics / Microsoft and are included here for personal,
  non-commercial preservation and fan use only.
* The original PINBALL.EXE is also included in the data folder and can be
  run through Wine if you prefer the absolute original binary.
